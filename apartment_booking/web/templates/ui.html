Quick Help & Booking Rules

Apartment Booker
  • Search & Book: Check available apartments by dates and guest count and book directly.
  • Create & Manage Bookings: Create new reservations, change dates/guests, or cancel bookings.
  • Apartments Directory: Browse all apartments with capacity and price filters.
System Manager
  • Apartments & Pricing: Add new apartments, update nightly rates, or remove apartments.
  • Bookings Overview: View reservation metrics and filter all bookings.
Core Booking Rules
  • Dates accept both YYYY-MM-DD and DD.MM.YYYY; check-out must be after check-in.
  • Back-to-back stays are allowed (check-in on an existing booking's check-out day). Overlapping stays are prevented.
  • Cancelled bookings are completely removed from the booking overview and release their dates immediately.
