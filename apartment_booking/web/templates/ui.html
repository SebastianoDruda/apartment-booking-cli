            Core Business Rules (Shared CLI & Web SQLite Engine)
            
    
              
  • Dates accept both ISO YYYY-MM-DD and European DD.MM.YYYY; check-out must be strictly after check-in.
    • 
              
  • Back-to-back stays are allowed (check-in on an existing booking's check-out day). Overlapping stays return 409 Conflict.
    • 
              
  • Cancelled bookings are completely removed from the booking overview and immediately release their date range.
    • 
              
  • Updating an apartment's nightly rate dynamically recalculates booking totals.
